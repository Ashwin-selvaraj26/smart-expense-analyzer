1. The "Smart" Expense Analyzer 📊
Focus: Data Manipulation (Pandas) & Visualization (Matplotlib)

The tutorial covered basic sales data. Now, apply that to messy, real-world data like a personal bank statement. This project strengthens your data science muscles.

** The Goal:** Build a script that ingests a CSV file of bank transactions, cleans the data, categorizes expenses (e.g., "Coffee", "Groceries", "Rent"), and generates a monthly spending chart.

Key Skills Used: pandas (DataFrames), matplotlib (visualizing data), str methods (cleaning currency symbols), and functions (logic for categorization).

The "Solid" Twist: Instead of hard-coding categories, create a mappings.json file that your script reads. If the description contains "Starbucks", map it to "Food". This separates your data from your code.
